## Features

- Home section
- Food categories
- Restaurant menu
- Special offer section
- Customer reviews
- Table reservation form
- Responsive design
- Navigation menu

## Technologies Used

- HTML5
- CSS3

## Project Purpose

This project was created to practice frontend web development using HTML and CSS.
